This project implements a deep learning pipeline for medical image classification using a pre-trained ResNet50 model, with a strong focus on model interpretability.

 **Features**

**Image classification using ResNet50**

Pre-trained model weights included (.pth file)

Model interpretability enhancements

Modular code structure (app.py, main.py, utils.py)
Easy deployment and testing

**Project Structure**

app.py                  # Application interface

main.py                 # Main execution script

utils.py                # Utility functions

requirements.txt        # Dependencies

resnet50_weight_best_model.pth  # Trained model weights
README.md               # Project documentation
**Installation**
git clone https://github.com/your-username/your-repo.git
cd your-repo
pip install -r requirements.txt
 Usage

Run the main application:

python main.py

Or launch the app interface:

python app.py
** Model**

**Architecture: ResNet50**

Framework: PyTorch

Task: Medical image classification

Includes interpretability improvements for better understanding of predictions.

**Notes**

Duplicate files (copy, old) are included for version tracking and experimentation.

Ensure the model weights file is in the root directory before running.
